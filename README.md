# ACM Church — Complete Mobile Web App

Free GitHub Pages / PWA-ready church website for Almighty Christ Ministries.

## Included
- Functional mobile hamburger drawer menu
- Bottom navigation
- Pastor portrait with plain background
- Church photo
- Sunday and weekly service schedule
- YouTube, Instagram and Facebook
- Phone and WhatsApp contact
- PWA manifest and service worker
