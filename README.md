# ACM Church Web App — First Version

Static PWA for ACM Church / Almighty Christ Ministries.

## Included
- Home, About, Service Schedule
- YouTube: https://youtube.com/@acmchurch
- Instagram: https://www.instagram.com/almighty_christ_ministries/
- Facebook: https://www.facebook.com/share/1DfoxtwSBa/
- Prayer Request via WhatsApp: 9894751914
- Contact and Google Maps
- User-supplied church, logo and pastor images
- PWA manifest + service worker

## Deploy
Upload all files/folders to GitHub Pages (or another static host). No server/database is required for this version.

Facebook is intentionally left out for now and can be added later.
